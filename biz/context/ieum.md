# 사업 컨텍스트: 이름과 이음 (ieum)

기준일 2026-11-14. 출처는 `yoobqoo/naming` 저장소의 코드와 문서.
저장소가 `../naming`에 있으면 에이전트는 이 문서보다 저장소의 최신 내용을 우선한다.
수치 표기: `[실측]` 코드·문서에서 확인 / `[계획]` 사업계획서의 가정 / `[미정]` 아직 값이 없음.

## 한 줄 정의

아이의 사주와 부모가 바라는 가치를 입력받아, 전통 작명 기준으로 계산한 이름 후보 3개와 근거 리포트를 유료로 제공하는 웹 서비스.
운영 주체는 던펙트(대표 1인 개발·운영, 외부 검수자 2인 위촉).

## 현재 단계

- 출시 전. 결제 실연동 전이며 실적 데이터 없음 `[실측]`
- 배포 주소: https://naming-green.vercel.app/
- 결제 키가 비어 있으면 결제 문(`PAYWALL`)이 꺼져 무료로 열리는 구조 `[실측]`
- 로그인: 카카오, 구글 (Supabase). 결제: 포트원 (카드, 카카오페이, 토스페이)

## 상품과 가격

| 항목 | 값 |
|---|---|
| 상품 | "우리 아이 이름과 풀이" 열람권, 단일 상품 `[실측]` |
| 가격 | 19,000원, 1회 구매, 구매 후 계속 열람 `[실측]` |
| 제공물 | 서로 다른 기준에서 1위인 이름 후보 3개 + 기준별 근거 리포트 `[실측]` |
| 검수 | 검수자 2인이 각각 확인 후 제공 `[계획]` (관리자 승인 화면은 미구현) |
| 환불 | 열람 전 전액 환불, 열람 후 원칙적으로 불가, 일부 사유는 열람 후에도 전액 `[실측]` |

## 이용 흐름

9단계 질문 입력(성, 생년월일·출생시간, 바라는 가치 등) → 엔진 계산 → 결제 → 검수 → 이름 3개와 리포트 열람.

## 단위경제 (채워야 할 표)

| 항목 | 값 |
|---|---|
| 객단가 | 19,000원 `[실측]` |
| PG 수수료 | 결제액의 3% 내외, 약 570원 `[계획]` |
| 검수 용역비 (건당) | `[미정]` 가장 중요한 빈칸 |
| 서버·도메인 (월) | `[미정]` |
| 건당 공헌이익 | 19,000 − 570 − 검수비 = `[미정]` |
| 허용 CAC 상한 | 공헌이익 미만 `[미정]` |
| 월 판매 가정 | 보수 20건 / 기본 50건 / 목표 100건 `[계획]` |
| 월 매출 가정 | 38만 / 95만 / 190만 원 `[계획]` |

구조적 사실:
- 작명은 아이 한 명당 한 번 사는 상품이다. 재구매가 거의 없으므로 LTV는 사실상 객단가 한 번이다.
  반복 매출은 둘째 아이, 추천(지인 소개), 상품 확장(개명, 태명, 상호 등)에서만 나온다.
- 따라서 CAC가 건당 공헌이익을 넘으면 팔수록 손해다 (P13).
- 목표치(월 100건)에서도 월 매출은 190만 원이다. 유료 광고와 검수비를 모두 감당하려면 무료 유입(검색, 추천) 비중이 커야 한다.

## 측정 상태

- 분석 도구가 코드에 없다 (GA4, 픽셀 등 없음) `[실측]`. 유입, 단계별 이탈, 결제 전환을 지금은 볼 수 없다.
- `index.html`에 `<meta name="robots" content="noindex">`가 있어 검색에 노출되지 않는다 `[실측]`. 출시 전 의도로 보이며, 공개 시점에 풀어야 한다.
- 메타 설명, OG 태그 없음. 본문은 자바스크립트로 그려지는 빈 셸(`<div id="app">`) `[실측]`.

## 차별점 (브랜드 약속)

1. 생성형 AI가 이름을 지어내지 않는다. 공개된 전통 규칙을 코드로 계산하며, 같은 입력이면 같은 결과가 나온다.
2. 어느 기준에서 어떤 값이 나왔는지 근거를 전부 공개한다.
3. 종합 점수나 별점을 매기지 않는다. 기준끼리 충돌하면 충돌한 채로 보여 준다.
4. 사람(검수자 2인)의 검수를 거친다.
5. 판단은 부모가 한다.

## 하면 안 되는 것 (P12 적용 대상)

디자인, 문구, 광고 모두에 적용된다. 위반하는 제안은 기각한다.

- "과학적으로 증명된", "이 이름은 100점", "이 이름이 아이의 운명을 바꿉니다", "완벽한 이름" 같은 표현
- 87점 같은 종합 점수, 별점
- 출처 없는 단정 ("이 이름은 좋습니다")
- 오행을 이모지 아이콘으로 표현 (점술 앱처럼 보인다)
- 스톡 아기 사진
- 아이의 생년월일·출생시간을 계산 외 목적(광고 타게팅 등)에 쓰는 것. 결과를 서버에 저장하지 않는 구조가 약속이다.

## 고객 (가설, 검증 전)

- 출산을 앞둔, 또는 갓 출산한 부모. 출생신고 기한(출생 후 1개월) 안에 결정해야 하므로 구매 시점이 짧고 분명하다.
- 대안: 오프라인 작명소(수만~수십만 원), 무료 작명 앱, 직접 짓기.
- 19,000원은 작명소보다 싸고 무료 앱보다 비싸다. 이 위치에서 돈을 내는 이유(근거 공개, 사람 검수)가 구매 전에 전달되는지가 전환의 관건이다.
