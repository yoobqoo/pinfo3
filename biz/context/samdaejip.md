# 사업 컨텍스트: 삼대집

기준일 2026-11-14. 출처는 `yoobqoo/samdaejip` 저장소 (`index.html` 한 파일, 마지막 커밋 2026-10-12).
저장소가 로컬에 있으면 에이전트는 이 문서보다 저장소의 최신 내용을 우선한다.
수치 표기: `[실측]` 코드에서 확인 / `[미정]` 아직 값이 없음.

## 한 줄 정의

"집단지성으로 정하는 진짜 3대 맛집". 지역·음식 종류별(예: 서울 3대 평양냉면)로 이용자가 투표해 3대 맛집을 정하고, 방문을 인증하는 모바일 웹앱(PWA).

## 현재 기능 `[실측]`

- 카테고리별 후보 목록과 순위, 카테고리당 최대 3표 투표
- 투표 후 7일간 변경 불가 (서버에서도 강제)
- 초기 순위는 에디터가 정한 순서(seed)로 채우고, 실제 표가 seed를 넘으면 실제 표로 대체
- 카카오 로그인 (투표, 한줄평, 좋아요에 필요)
- 사진 인증(EXIF 촬영일)으로 방문 확인, 3곳 완주 시 뱃지 ("성지순례")
- 한줄평, 좋아요
- "순위 경쟁이 가장 치열한 곳" 노출 (3위와 4위의 표 차)
- 후보지 제안은 "곧 열려요" 상태 (미구현)
- 데이터: Supabase + 구글 시트, 시트 로드 실패 시 내장 데이터

## 수익 모델

- 현재 수익 없음 `[실측]`
- 코드에 네이티브 앱의 AdMob 배너 자리(약 50px)를 확보해 둔 흔적이 있다. 광고 수익을 염두에 둔 것으로 보이나 확정 아님 `[미정]`
- 가능한 방향(검증 전): 광고, 식당 제휴·예약 연결 수수료, 지역 광고

## 단위경제 (채워야 할 표)

| 항목 | 값 |
|---|---|
| 월 방문자 | `[미정]` |
| 가입(카카오 로그인) 전환율 | `[미정]` |
| 투표 참여율 | `[미정]` |
| 7일·30일 재방문율 | `[미정]` |
| 방문자 1인당 수익 | 0원 `[실측]` |
| 월 고정비 (서버 등) | `[미정]` |

구조적 사실:
- 광고 모델은 방문자당 수익이 매우 작다. 유료 광고로 사람을 데려오면 거의 항상 손해이므로, 성장은 검색·공유·재방문에서 나와야 한다 (P13).
- 이음과 반대로 삼대집은 재방문이 사업의 본체다. 핵심 지표는 매출이 아니라 재방문율과 투표 수다.
- 투표 수가 적은 초기에는 순위의 신뢰가 seed(에디터 선정)에 의존한다. "집단지성"이라는 약속과 실제의 간격이 신뢰 위험이다.

## 측정 상태 `[실측]`

- 분석 도구 없음 (GA4 등 없음)
- 메타 설명, OG 태그 없음. 카카오톡으로 공유했을 때 미리보기가 비어 보일 가능성이 높다.
- 한 파일짜리 앱이라 카테고리별 고유 주소가 검색에 잡히는지 확인이 필요하다. "서울 3대 평양냉면" 같은 검색어는 이 서비스에 가장 맞는 유입원이다.
- `user-scalable=no`로 화면 확대를 막아 두었다 (접근성 문제).

## 하면 안 되는 것 (P12 적용 대상)

- 돈을 받고 순위를 올려 주는 것, 또는 그렇게 보이는 것. 순위의 독립성이 유일한 자산이다.
- 가짜 표, 가짜 한줄평. seed 표는 실제 표와 구분해서 다뤄야 한다.
- 광고를 순위 결과처럼 보이게 배치하는 것.
