# 결정 로그

경영회의(`/board`)의 결정을 최신순으로 기록한다 (P11).
점검일이 되면 "실제 결과"와 "배운 것"을 채우고, 필요하면 `principles.md`를 고친다 (P10).

## 양식

```
## D-번호 · 날짜 · 사업 · 안건 제목
- 결정: 승인 / 조건부 승인 / 보류 / 기각
- 근거 원칙: P번호
- 핵심 가정: (틀리면 결론이 바뀌는 것)
- 예상 결과: (지표와 수치)
- 최대 손실: (돈, 시간)
- 중단 기준:
- 점검일:
- 실제 결과: (점검일에 기록)
- 배운 것: (점검일에 기록)
```

## 기록

## D-001 · 2026-11-16 · 이음 · 2단 가격 구성 (A 작명 / B 후보 검토)
- 결정: 보류 (유료 2단 구성). 세부: 1:6 저가 B 기각, 30만/5만 원대 전환 기각, 검수 포함 유료 B 보류, B 무료 유지 + 측정 + A 연결 버튼 승인(E-001), 검수 원가 실측 조건부 승인(E-002)
- 근거 원칙: P1, P2, P4, P5, P6, P7, P8, P9, P12, P13
- 핵심 가정:
  (1) 검수비는 2인 합계 건당 2,000~10,000원이다 [가정]. 10,000원 이상이면 가격 구조보다 A 자체의 가격·검수 방식이 먼저다.
  (2) 무료 B 이용자가 A 구매층(출산 전후 부모)과 상당 부분 겹친다 [가정]. 겹치지 않으면 B→A 전환이 낮아도 유료 B의 근거가 되지 않는다.
  (3) 30만/5만 원은 예시이며 실제 목표가가 아니다 [미확인]. 실제 목표가라면 별도 안건으로 다시 심사한다.
  (4) 유료였다면 B 결제율은 5% 안팎이다 [가정]. 성공 기준 2%가 여기서 나왔다.
- 예상 결과: E-002로 2026-11-30까지 A형·B형 1개 검수 원가가 실측된다. E-001로 출시 후 8주 안에 B 완료자의 A 결제 전환율(예상 1~3%, 확신 낮음)과 랜딩 B 클릭 비중(예상치 없음, 첫 수치가 기준선)을 얻는다.
- 최대 손실: 현금 15만 원, 대표 시간 약 12시간 (개발 8시간 + 검수 의뢰 4시간). 무료 B가 A를 잠식하는 크기는 미측정.
- 중단 기준: E-002는 15만 원 도달 또는 2주 내 검수자 일정 미확정. E-001은 개발 8시간 초과 시 이벤트만 남김, 출시 후 8주에 B 완료 100건 미만이면 안건 종료 후 유입을 다음 안건으로.
- 점검일: 2026-11-30 (E-002 결과, E-001 구현 여부, 대표의 가격 의도 확인). 이후 출시일 + 4주, + 8주.
- 재심사 대기:
  - 검수 포함 유료 B: E-001에서 A 전환 1% 미만이고 B 클릭 비중 30% 이상이며, E-002에서 B형 1개 원가가 A형의 2분의 1 이하일 때. 이름 1개 구성으로 다시 설계.
  - A가 '마음에 둔 이름'도 풀이: E-001에서 입력률 30% 이상일 때 [기준은 가정].
  - 이름 풀이 정적 페이지(SEO): 검색어 월 검색량 확인과 noindex 해제 시점 확정 후.
- 출시 전 별도 안건 (P12): 검수 흐름 미구현 상태의 "두 명의 검토자" 문구, 결제 문을 우회하는 공유 링크, 자리표시 후기 3건.
