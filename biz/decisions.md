# 결정 로그

경영회의(`/board`)의 결정을 최신순으로 기록한다 (P11).
점검일이 되면 "실제 결과"와 "배운 것"을 채우고, 필요하면 `principles.md`를 고친다 (P10).

## 양식

```
## D-번호 · 날짜 · 사업 · 안건 제목
- 결정: 승인 / 조건부 승인 / 보류 / 기각
- 근거 원칙: P번호
- 핵심 가정: (틀리면 결론이 바뀌는 것)
- 예상 결과: (지표와 수치)
- 최대 손실: (돈, 시간)
- 중단 기준:
- 점검일:
- 실제 결과: (점검일에 기록)
- 배운 것: (점검일에 기록)
```
