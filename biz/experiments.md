# 실험 대장

진행 중인 실험은 사업당 최대 2개 (P9). 성공·중단 기준은 시작 전에 적고 결과를 본 뒤 바꾸지 않는다 (P7).

## 양식

```
## E-번호 · 사업 · 실험 이름
- 관련 결정: D-번호
- 가설: (무엇을 바꾸면 어떤 지표가 얼마나 움직인다)
- 지표: (1차 지표 하나, 보조 지표)
- 기준선: (현재 값, 없으면 측정부터)
- 필요 표본 / 기간:
- 예산 상한:
- 성공 기준:
- 중단 기준:
- 상태: 대기 / 진행 중 / 종료
- 결과:
```

## 진행 중

## E-001 · 이음 · 무료 이름 풀이(B)의 A 전환 측정
- 관련 결정: D-001
- 가설: B 결과 화면에 A로 가는 버튼을 두면 B 완료자의 2% 이상이 A를 결제한다 [가정]
- 지표: 1차 B 완료자의 A 결제 전환율 / 보조 랜딩 클릭 중 B 비중, 살펴볼 점 유무별 A 진입 클릭률, 마음에 둔 이름 입력률
- 기준선: 없음 (분석 도구 없음. 측정부터)
- 필요 표본 / 기간: B 완료 300건 또는 출시 후 8주 중 먼저 오는 쪽. 방향 판단용 (300건에서 95% 오차 약 ±1.6%p)
- 예산 상한: 현금 0원, 개발 8시간
- 성공 기준: 전환율 2% 이상 → B 무료 유지 확정
- 중단 기준: 1% 미만이고 B 비중 30% 이상 → 유료 B 재심사 / 1~2% → 600건 또는 16주까지 1회 연장 / 8주에 B 완료 100건 미만 → 안건 종료, 유입을 다음 안건으로
- 구현 범위: 이벤트 7개(landing_view, cta_generate, cta_evaluate, evaluate_result_view + 살펴볼 점 유무, evaluate_to_generate, pay_done, 마음에 둔 이름 입력 여부). 이름·생년월일·한자는 싣지 않는다. B 결과 하단에 A 보조 버튼(항상 노출, 중립 문구), 비검수 고지 한 줄, 랜딩 "· 무료" 표기, evaluate.ts 348행 문구 교체
- 상태: 대기 (구현 후 출시일에 진행 중으로 변경)
- 결과:

## E-002 · 이음 · 검수 건당 비용·시간 실측
- 관련 결정: D-001
- 가설: A형(이름 3개와 리포트) 검수 원가는 2인 합계 건당 2,000~10,000원 사이다 [가정]
- 지표: 1차 유형별 건당 원가(원) / 보조 건당 소요 분, 두 검수자 판단 불일치율
- 기준선: 없음 [미정]
- 필요 표본 / 기간: 견본 20건 (A형 10, B형 이름 1개 10. B형에는 흔치 않은 한자를 섞는다) / 2주
- 예산 상한: 15만 원, 대표 시간 4시간
- 성공 기준: A형과 B형 1개의 건당 원가·시간이 실측으로 확정
- 미리 정한 판정: A형 원가 10,000원 이상이면 A의 가격·검수 방식을 다음 안건으로 / B형 1개 원가가 A형의 2분의 1을 넘으면 검수 포함 저가 B 기각 확정
- 중단 기준: 15만 원 도달, 또는 2주 안에 검수자 일정 미확정
- 상태: 대기 (대표가 검수자에게 의뢰하면 진행 중으로 변경)
