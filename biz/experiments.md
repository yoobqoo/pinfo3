# 실험 대장

진행 중인 실험은 사업당 최대 2개 (P9). 성공·중단 기준은 시작 전에 적고 결과를 본 뒤 바꾸지 않는다 (P7).

## 양식

```
## E-번호 · 사업 · 실험 이름
- 관련 결정: D-번호
- 가설: (무엇을 바꾸면 어떤 지표가 얼마나 움직인다)
- 지표: (1차 지표 하나, 보조 지표)
- 기준선: (현재 값, 없으면 측정부터)
- 필요 표본 / 기간:
- 예산 상한:
- 성공 기준:
- 중단 기준:
- 상태: 대기 / 진행 중 / 종료
- 결과:
```

## E-002 · 이음 · 14.9만/4.9만 원 사양의 검수 원가·납기 실측
- 관련 결정: D-002 (D-001의 설계를 대체)
- 가설: 2인 합계 원가는 작명 10,000~60,000원, 감명 7,000~40,000원 사이다 [가정]
- 지표: 1차 유형별 건당 원가(원) / 보조 건당 소요 분, 납기(일), 두 검수자 불일치율, 자원오행 글자당 소요 분과 500~800자 견적
- 기준선: 없음 [미정]
- 필요 표본 / 기간: 작명형 5건, 감명형 5건(한글 이름 3개에 한자 고르기), 자원오행 시범 50자 / 2주. 단가가 가정보다 높으면 유형별 3건까지 축소
- 예산 상한: 30만 원, 대표 시간 6시간
- 성공 기준: 유형별 원가·납기와 자원오행 검수본 총비용이 실측으로 확정
- 미리 정한 판정: 감명형 30,000원 초과면 3개 4.9만 원 구성 기각 후 축소·인상안 재심사 / 작명형 60,000원 초과면 사양 축소 후 재견적 / 납기 3일 초과면 사양 축소 / 실명·경력 공개 거절이면 "전문 성명학자" 문구 없이 가격 재심사
- 중단 기준: 30만 원 도달, 또는 2주 안에 검수자 일정 미확정
- 상태: 대기 (대표가 사양 한 장을 쓰고 의뢰하면 진행 중)
- 결과:

## E-003 · 이음 · 수동 판매로 14.9만/4.9만 원 지불 의사 확인
- 관련 결정: D-002
- 가설: 출산 전후 부모 20명에게 견본과 가격표를 보여 주면 3명 이상이 작명 14.9만 원을 결제한다 [가정]
- 지표: 1차 가격을 본 사람 중 작명 결제 비율 / 보조 감명 결제 비율, 감명 대 작명 선택 비율, 거절 이유("결론이 없다"는 따로 집계), 환불 요청, 세 질문 응답(무엇을 받나, 누가 보나, 마음에 안 들면)
- 기준선: 없음
- 필요 표본 / 기간: 제안 20명 또는 4주. 방향 판단용
- 예산 상한: 환불 시 검수비 손실 30만 원, 대표 시간 20시간
- 성공 기준: 20명 중 작명 3건 이상. 2건이면 10명을 1회 추가해 30명 중 4건 이상
