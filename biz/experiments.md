# 실험 대장

진행 중인 실험은 사업당 최대 2개 (P9). 성공·중단 기준은 시작 전에 적고 결과를 본 뒤 바꾸지 않는다 (P7).

## 양식

```
## E-번호 · 사업 · 실험 이름
- 관련 결정: D-번호
- 가설: (무엇을 바꾸면 어떤 지표가 얼마나 움직인다)
- 지표: (1차 지표 하나, 보조 지표)
- 기준선: (현재 값, 없으면 측정부터)
- 필요 표본 / 기간:
- 예산 상한:
- 성공 기준:
- 중단 기준:
- 상태: 대기 / 진행 중 / 종료
- 결과:
```
